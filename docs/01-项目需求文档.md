## 1. 项目概述

### 1.1 背景

车间/办公室的打印机（典型如 **EPSON LQ-630K 针式打印机**）通过 USB 或并口连接在一台 Windows 主机上，只在该主机本地可用。多台客户端电脑需要共享打印，常见做法是 Windows 的 `\\主机\打印机` 共享，但该方案存在硬伤：

- Windows 11 客户端默认禁用 SMB1，**无法访问 Windows 7 主机**的共享；
- Windows 10（2004 起）对共享有签名要求，跨版本共享常出现认证/签名失败；
- 共享方案把主机上**所有打印机**（含 PDF/传真等虚拟打印机）暴露给所有人，无法只开放指定打印机；
- 修改共享/端口配置必须登录主机操作配置文件或控制面板，无远程图形化管理手段。

### 1.2 项目目标

把主机上的本地打印机转换为**网络打印服务器**，使局域网内 Windows 7/10/11 客户端通过标准 TCP/IP 打印端口直接打印，且满足：

1. 客户端零特殊依赖（Windows 原生功能即可接入）；
2. **只转换指定的打印机**，其余打印机不开放任何端口；
3. 提供**带登录鉴权的网页图形化配置**，管理员无需手改配置文件，且防止他人随意改动；
4. 单文件部署、开机自启、可远程排障。

### 1.3 项目范围

**包含**：RAW 打印协议服务端、LPD 打印协议服务端、Windows 打印后台（winspool）转发、端口自动分配与持久化、打印机筛选与选择、只读状态页、登录鉴权的网页配置台、Windows 服务安装、防火墙自动放行、日志与自检、客户端接入脚本（Win7 / Win10+）。

**不包含**：客户端驱动的开发与分发（使用厂商真实驱动）；公网暴露与 HTTPS（如需请自行加反代）；打印作业内容的加密与审计；SMB 共享方式（有意排除，见 1.1）；云打印/移动 App 接入。

## 2. 术语表

| 术语 | 含义 |
|---|---|
| RAW 端口 | 标准 TCP/IP 打印端口协议（JetDirect，默认 9100），客户端把打印机语言字节流直接发到该 TCP 端口 |
| LPD/LPR | RFC 1179 行式打印机守护进程协议（默认 515），Windows 客户端可通过「LPR 端口监视器」接入 |
| 队列（Queue） | LPD 协议中的打印机标识名，本项目自动分配为 `PRN1、PRN2…` |
| 虚拟打印机 | 软件型打印机（打印到 PDF/XPS/传真/虚拟绘图仪等），输出为文件而非纸张 |
| 端口粘性 | 打印机与端口的映射持久化在 `config.state.json`，重启后不变 |
| 热应用 | 保存配置后不重启服务/不重启系统，程序内部重新加载并重启所有监听 |
| 回滚 | 新配置无法生效时，自动恢复旧配置与旧监听，保证管理入口不丢失 |

## 3. 用户角色与典型场景

| 角色 | 描述 | 使用的入口 |
|---|---|---|
| 车间操作员（客户端用户） | 在自己电脑上打印票据/单据 | Windows「添加打印机」向导，或运行 `client` 脚本 |
| 系统管理员（James/运维） | 部署服务器、选择要开放的打印机、改端口、排查问题 | 网页配置台 `/config`、CLI 命令、`diag` 自检 |
| 普通旁观者 | 局域网内其他人 | 只能看只读状态页 `/`，不能改任何配置 |

**核心场景 A（部署）**：在接打印机的主机上双击 `安装为服务.bat` → 服务创建并立即启动、防火墙放行、打印初始管理员口令 → 管理员在浏览器打开 `/config` 登录 → 勾选要转换的打印机 → 保存并应用。

**核心场景 B（客户端打印）**：客户端运行 `client\install-win10.ps1 -Server 192.168.0.19 -Driver "EPSON LQ-630K"` → 自动创建 TCP/IP RAW 端口与打印机并打印测试页；之后日常打印与本地打印无差别。

**核心场景 C（排障）**：客户端打不出 → 管理员先看状态页「最近作业」，再在服务器跑 `netprintserver.exe diag`，把输出发给支持人员定位。

## 4. 功能需求

优先级：P0 = 必须；P1 = 重要；P2 = 增强。

### 4.1 打印核心

| 编号 | 需求 | 优先级 | 验收标准 | 状态 |
|---|---|---|---|---|
| FR-01 | 监听 TCP 端口接收客户端 RAW 打印数据，并原样提交到本机 Windows 打印队列 | P0 | 客户端以真实驱动打印，主机打印机出纸；服务端不做任何数据转换（数据类型 RAW） | 已实现 v1.0.0 |
| FR-02 | 支持 LPD/LPR（RFC 1179）作为备选接入协议，含队列名校验与状态查询命令 | P1 | 客户端 LPR 端口指向服务器与队列名可打印；未知队列返回错误码 2 | 已实现 v1.0.0 |
| FR-03 | 打印机忙/脱机时由 Windows 打印后台排队，多客户端并发互不影响 | P0 | 并发提交多个作业按序执行，不丢作业 | 已实现 v1.0.0（依赖 spooler） |
| FR-04 | 单个作业大小上限与客户端空闲超时可配置 | P1 | 超限作业拒绝；发完数据不关连接的客户端在超时后按已收数据提交 | 已实现 v1.0.0 |
| FR-05 | 支持 64 位与 32 位两个可执行文件，兼容老 Win7 | P1 | x64 与 x86 exe 均可在对应系统运行 | 已实现 v1.0.0 |

## 6. 约束与假设

1. **客户端必须安装与打印机匹配的真实驱动**（如 EPSON LQ-630K），服务端只做字节转发，字体/页宽/纸张由客户端驱动决定；
2. 服务器主机需能本地正常打印（驱动安装、打印测试页通过）是本项目工作的前提；
3. 所有组件运行于同一局域网，IP 由内网 DHCP/静态分配；`bind_ip` 用于限定对外网卡；
4. 服务器账户：服务以 LocalSystem 运行（具备防火墙配置权限）；前台运行时非管理员仅跳过防火墙配置并提示；
5. 不修改、不依赖 Windows 打印后台之外的系统组件；不注入、不 Hook；
6. 源码以 Go 语言开发，构建在 Linux 交叉编译为 Windows 可执行文件（CI 无 Windows 机器，真机验证依赖部署方实测）。

## 7. 验收标准（UAT 清单）

**服务器端**
- [ ] `netprintserver.exe install` 后服务状态为「运行中」，重启机器自动启动
- [ ] 状态页 `http://<IP>:8080/` 打开，打印机列表与「设备和打印机」一致
- [ ] `bind_ip` 设定后：本机 `http://127.0.0.1:8080` 可访问，其它网卡地址拒绝
- [ ] 状态页点「打印测试页」→ 主机打印机出纸
- [ ] 防火墙出现规则 `NetPrintServer`（TCP 9100/515/8080，enabled=yes）
- [ ] `diag` 输出 winspool 函数全部 OK、打印机枚举正常
- [ ] `netprintserver.log` 记录每次作业的来源与字节数

**配置台**
- [ ] 未登录访问 `/config` 跳转登录；状态页不受影响
- [ ] 初始口令可在安装输出/日志中找到；`password` 命令可重置
- [ ] 连续错 5 次被锁定 60 秒
- [ ] 勾选模式下只勾 1 台 → 仅该打印机有端口，其它无监听
- [ ] 保存改端口 → 无需重启服务即生效；故意把端口改到被占用 → 自动回滚且页面提示

**客户端**
- [ ] Win10/11 与 Win7 各接入一台，打印 Windows 测试页成功
- [ ] 两个客户端并发打印互不干扰
- [ ] LPR 备选路径可选验证
