# NetPrintServer 接口文档

| 项目 | 内容 |
|---|---|
| 版本 | 与程序 v1.1.1 对应 |
| 默认端口 | RAW 打印 9100（自动分配起始值）、LPD 515、状态页/配置台 8080 |
| 认证 | 状态页只读公开；配置台需登录会话 + CSRF 头 |
| 响应编码 | 一律 UTF-8；JSON 统一 `{ok, note|error}` 结构（另有标注除外） |

---

## 1. 端口总览

| 端口 | 协议 | 用途 | 默认 | 配置项 |
|---|---|---|---|---|
| 9100、9101… | TCP RAW | 客户端「标准 TCP/IP 打印端口」接入 | `start_port` 起自动分配 | `start_port` / `bindings[].port` |
| 515 | TCP（RFC 1179） | LPR/LPD 接入 | 515 | `lpd_enabled` / `lpd_port` |
| 8080 | HTTP | 状态页、配置台、API | 8080 | `web_port` |

监听地址规则（`bindPort`）：
- `bind_ip` 为空 → 监听全部网卡 `:port`
- `bind_ip` = 某网卡 IP → 监听 `IP:port` **并额外监听 `127.0.0.1:port`**（本机 localhost 恒可访问）
- `bind_ip` 为回环地址 → 只监听该回环

## 2. HTTP 接口

### 2.1 路由总表

| 方法 | 路径 | 鉴权 | 用途 |
|---|---|---|---|
| GET | `/` | 公开 | 状态页 HTML（只读） |
| GET | `/healthz` | 公开 | 健康检查，返回 `ok` |
| GET | `/api/status` | 公开 | 状态 JSON |
| POST | `/api/test` | `token` 表单字段 | 向指定打印机发送测试页 |
| GET | `/login` | — | 登录页 HTML |
| POST | `/login` | — | 登录（表单） |
| POST | `/logout` | 会话 | 退出登录 |
| GET | `/config` | 会话 | 配置台 HTML（未登录 302 → `/login`） |
| GET | `/api/whoami` | 会话可选 | 查询是否已登录 |
| POST | `/api/config` | 会话 + CSRF | 保存并热应用配置 |
| POST | `/api/password` | 会话 + CSRF | 修改管理员口令 |

### 2.2 认证与安全规范

| 项 | 规则 |
|---|---|
| 会话 Cookie | `nps_admin`，`HttpOnly`、`SameSite=Lax`、`Path=/`，有效期 12 小时（无操作过期），服务端校验 |
| CSRF | 所有 POST **配置/口令**接口必须带请求头 `X-NPS-Auth: 1`，且 `Origin`（若存在）必须与请求 `Host` 同源，否则 403 |
| 登录失败 | 连续 5 次失败锁定 60 秒；锁定期内即使口令正确也返回 429 |
| 口令存储 | `admin_password_hash` = `盐(32位hex)$SHA256(盐+口令)`，恒定时间比较 |
| 未鉴权访问 | HTML 路径 → `302 /login`；`/api/*` → `401` JSON |
| 默认账号 | 用户名 `admin`（`admin_user`），口令首次运行随机生成并打印 |

### 2.5 POST /api/test

表单（`application/x-www-form-urlencoded`）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `printer` | 是 | 打印机名（须在已转换列表中） |
| `token` | 是 | 配置项 `web_token`（状态页按钮自动携带） |

响应：

```

400 {"ok":false,"error":"打印机「xx」不可用"}
405 {"ok":false,"error":"仅支持 POST"}
```

### 2.6 登录 / 会话

**POST /login**（表单 `user`、`pass`）

| 情况 | 状态码 | 行为 |
|---|---|---|
| 成功 | 302 → `/config` | `Set-Cookie: nps_admin=<32字节hex>; HttpOnly; SameSite=Lax` |
| 口令错误 | 401 | 返回登录页 HTML（含错误提示） |
| 锁定中 | 429 | 返回登录页 HTML（提示 60 秒后再试） |

**GET /api/whoami**：`{"ok":true,"auth":true,"user":"admin"}` 或 `{"ok":false,"auth":false}`

**POST /logout**：清除会话与 Cookie，302 → `/login`

### 2.7 GET /config

需登录。返回配置台 HTML，页面内嵌当前配置与本机打印机清单（含勾选状态、端口分配、跳过原因）。

### 2.8 POST /api/config（保存并热应用）

请求头：`Content-Type: application/json`、`X-NPS-Auth: 1`，并携带会话 Cookie。

```jsonc
{
  "server_name": "车间打印服务",
  "bind_ip": "",                    // 空=全部网卡；否则该网卡 IP（127.0.0.1 恒可访问）
  "start_port": 9100,
  "lpd_enabled": true,
  "lpd_port": 515,
  "web_enabled": true,              // 服务端强制保持 true，网页端不允许关闭状态页
  "web_port": 8080,
  "firewall": true,
  "max_job_mb": 100,                // 1~4096
  "idle_timeout_sec": 60,           // 5~600
  "selection_mode": "selected",     // selected | auto | all
  "selected_printers": ["EPSON LQ-630K"],
  "include_keywords": [],           // 服务端会按 , ， ; ； 换行 再切分去重
  "exclude_keywords": ["PDF","XPS"],
  "keep_virtual_printers": false,
  "bindings_json": "[{\"port\":9100,\"queue\":\"PRN1\",\"printer\":\"EPSON LQ-630K\"}]"  // JSON 文本
}
```

**校验规则**（失败 → 400，`error` 为中文可读信息）：
- 端口 1~65535，`start_port`/`lpd_port`/`web_port` 两两不冲突；
- `selection_mode ∈ {auto,selected,all}`；`selected` 模式下 `selected_printers` 至少 1 个；
- `max_job_mb` 1~4096；`idle_timeout_sec` 5~600；`bind_ip` 为空或合法 IP；
- `bindings_json` 须为合法 JSON 数组，元素含非空 `printer` 与合法 `port`，端口不重复。

**成功响应**（先应答、后热应用）：

```json
{"ok":true,"note":"配置已保存，正在重新应用监听…"}
```

端口/网卡变更时 `note` 变为：`配置已保存，正在切换到新端口 8090；若新地址打不开，程序会自动回滚到原配置（详见 netprintserver.log）`

**热应用流程**：写 `config.json` → 400ms 后 `Stop()` 全部监听 → 载入新配置 `Start()` → 失败则**回滚**（恢复旧配置、写回配置文件、重启旧监听）并把结果记入 `netprintserver.log` 与配置页「上次应用」横幅。

**错误码汇总**：

| 状态码 | 含义 |
|---|---|
| 401 | 未登录/会话过期 |
| 403 | 缺少 `X-NPS-Auth` 头，或 `Origin` 跨站 |
| 400 | 配置校验失败 / JSON 解析失败 / 口令不足 6 位 |
| 405 | 非 POST |
| 429 | 登录锁定 |

### 2.9 POST /api/password

请求体：`{"password":"newSecret9"}`（需会话 + `X-NPS-Auth: 1`）

```
200 {"ok":true,"note":"口令已修改，其它设备需要重新登录"}
```

## 3. RAW 打印协议（TCP，默认 9100）

| 项 | 说明 |
|---|---|
| 连接 | 客户端（Windows 标准 TCP/IP 打印端口）建立 TCP 连接 |
| 传输 | 客户端单向发送打印机语言字节流（LQ-630K 即 ESC/P），**服务器不回发任何数据** |
| 结束 | 客户端关闭连接（正常路径）；或超过 `idle_timeout_sec`（默认 60 秒）无新数据 → 按已收数据提交 |
| 空连接 | 0 字节即关闭 → 忽略，不产生作业 |
| 超限 | 累计超过 `max_job_bytes` → 中止作业并记日志 |
| 并发 | 每连接独立作业，互不阻塞；排队交给 Windows spooler |
| 错误 | 打印机不可用/打开失败 → 关闭连接（服务端日志记录，客户端在下一次打印时重试） |

客户端接入参数：主机 = 服务器 IP，端口 = 该打印机分配到的 RAW 端口，协议 RAW，**SNMP 关闭**，驱动 = 打印机真实型号。

## 4. LPD 打印协议（TCP 515，RFC 1179）

### 4.1 接收作业时序

```
客户端                                   服务器
  │  \x02 + 队列名 + \n                    │   队列不存在 → 回 "2\n" 并关闭
  ├───────────────────────────────────────►│   打印机不可用 → 回 "1\n" 并关闭
  │◄────────────── "0\n" ──────────────────┤
  │  控制文件（H主机 P用户 J文档名…）+ \x02  │
  ├───────────────────────────────────────►│
  │◄────────────── "0\n" ──────────────────┤
  │  数据文件字节流 + \x02（或直接关闭连接）  │
  ├───────────────────────────────────────►│  提交到 Windows 队列
  │◄────────────── "0\n" ──────────────────┤
```

- 首命令：`\x01` 或 `\x02` + 队列名 + LF；
- 数据文件终止：`\x02` 字节，**或连接关闭，或静默 10 秒**（兼容不发终止符的客户端）；
- 队列名：自动分配 `PRN1、PRN2…`（也接受打印机名本身，不区分大小写）；
- 作业标题取控制文件 `J` 字段，其次 `f/c/m/l`。

### 4.2 其它命令

| 命令 | 行为 | 响应 |
|---|---|---|
| `\x03`+队列 | 删除作业（不跟踪外部作业） | `1\n`（未找到） |
| `\x04`+队列 | 队列状态 | 文本行（`Printer: …`），随后关闭连接 |
| `\x05`+服务器名 | 服务器状态 | 文本行（Server/Protocol/Queues），随后关闭 |
| 未知命令 | 记日志后关闭 | 无 |

## 5. CLI 命令

| 命令 | 权限 | 说明与输出要点 |
|---|---|---|
| `netprintserver [run] [-config 路径]` | 普通/管理员 | 前台运行；打印客户端连接信息；Ctrl+C 优雅退出。被 SCM 启动时自动转为服务模式 |
| `install [-config 路径]` | **管理员** | 创建服务 `NetPrintServer`（自动启动）+ 配置防火墙 + 立即启动并打印状态；首次生成初始口令 |
| `uninstall` | **管理员** | 停止并删除服务（配置与日志保留） |
| `start` / `stop` | **管理员** | 启动/停止服务 |
| `status` | 普通 | 服务状态 + 端口分配预览（含离线标记） |
| `diag` | 普通 | 自检：本机 IP、服务状态、端口分配、跳过清单、winspool 9 个函数可用性、EnumPrinters 原始 ret/err/needed/count、每台打印机详情与句柄测试 |
| `printers` | 普通 | 列出本机打印机（状态/端口/驱动） |
| `password [新口令]` | 管理员（建议） | 设置网页配置台口令；不给参数则随机生成并打印；打印后需 `net stop/start` 生效 |
| `version` / `help`（`-V`/`-h`） | 普通 | 版本 / 帮助 |

退出码：参数或启动错误为 1；panic 兜底为 70（并打印「内部错误（已捕获）」）。

## 6. 配置文件 config.json（完整 Schema）

位置：exe 同目录；`-config` 可指定；相对路径以配置文件目录为基准解析。

| 字段 | 类型 | 默认 | 说明/范围 |
|---|---|---|---|
| `server_name` | string | NetPrintServer 网络打印服务器 | 状态页标题 |
| `bind_ip` | string | `""` | 空=全部网卡；合法 IP=只监听该网卡+回环 |
| `backend` | string | `auto` | `auto`/`windows`/`file`（file=作业写 .prn 文件） |
| `file_output_dir` | string | `spool` | file 后端输出目录 |
| `file_printers` | string[] | `["LQ630K"]` | file 后端模拟的打印机名 |
| `auto_assign` | bool | `true` | 是否自动为新打印机分配端口 |
| `start_port` | int | 9100 | 自动分配起始端口（也是校验冲突的基准） |
| `bindings` | array | `[]` | 手动绑定：`{port, queue, printer, comment}`，优先级最高，可覆盖筛选 |
| `lpd_enabled` | bool | `true` | 是否启用 LPD |
| `lpd_port` | int | 515 | LPD 端口 |
| `web_enabled` | bool | `true` | 是否启用状态页/配置台（网页端不可关闭） |
| `web_port` | int | 8080 | HTTP 端口 |
| `web_token` | string | 随机 16 位 hex | `/api/test` 令牌 |
| `firewall` | bool | `true` | 启动/热应用时自动更新防火墙规则（需管理员） |
| `max_job_bytes` | int | 104857600 | 单作业上限；校验 1MB~4096MB |
| `idle_timeout_sec` | int | 60 | RAW 客户端空闲超时；校验 5~600 |
| `log_file` | string | `netprintserver.log` | 日志路径 |
| `version` | string | — | 生成时的程序版本 |
| `include_keywords` | string[] | `[]` | 非空时仅名称/驱动命中者参与自动分配 |
| `exclude_keywords` | string[] | PDF,XPS,Fax,传真,OneNote,Virtual,虚拟,导出,WPS,pdfFactory,Software Printer | 名称或驱动命中即跳过（留空=恢复默认规则） |
| `exclude_port_prefixes` | string[] | PORTPROMPT:,FILE:,SHRFAX:,FPP,NUL:,RDP,TSC | 端口前缀命中即跳过 |
| `keep_virtual_printers` | bool | `false` | true=不做任何过滤 |
| `selection_mode` | string | `auto` | `selected` 只转换 `selected_printers` / `auto` 自动过滤 / `all` 全部 |
| `selected_printers` | string[] | `[]` | 被勾选的打印机名（不区分大小写；`selected` 模式下至少 1 个） |
| `admin_user` | string | `admin` | 配置台用户名 |
| `admin_password_hash` | string | 首次运行生成 | `盐$SHA256(盐+口令)`，明文不落盘 |

**state 文件 config.state.json**（端口粘性，自动维护）：

```jsonc
{ "assign": { "EPSON LQ-630K": { "port": 9100, "queue": "PRN1" } } }
```

**优先级**：手动 `bindings` > 历史 `state` 分配 > 自动分配（`start_port` 起最小空闲端口）。被筛选跳过的打印机会从 `state` 中清理。

## 7. 服务与防火墙对象

| 对象 | 值 |
|---|---|
| Windows 服务名 | `NetPrintServer`（显示名：NetPrintServer 网络打印服务器，启动类型=自动） |

## 8. 状态码速查

| 场景 | 状态码 |
|---|---|
| 正常读取/保存 | 200 |
| 未登录访问配置页 | 302 → /login |
| 未登录调配置 API | 401 |
| 口令错误（登录） | 401 |
| 缺 CSRF 头 / 跨站 Origin | 403 |
| 测试页令牌错误 | 403 |
| 配置校验失败 / 口令过短 / JSON 非法 | 400 |
| 方法不允许 | 405 |
| 登录锁定 | 429 |
