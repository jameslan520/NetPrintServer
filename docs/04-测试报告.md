## 1. 测试范围与方法

| 层次 | 方法 | 环境 |
|---|---|---|
| 协议层（RAW/LPD/HTTP） | Go 自动化测试，file 后端落盘字节比对 | Linux |
| 配置与选择逻辑 | 单元/集成测试（含真实枚举数据样本） | Linux |
| 网页鉴权与热应用 | 自动化测试（HTTP 客户端模拟登录/越权/回滚场景） | Linux |
| Windows API 调用层 | 无法在 Linux 执行 → **接口隔离 + 结构体布局比对 + 源码级守卫测试** | Linux（静态） |
| Windows 真机行为 | 部署方实测（diag/install/状态页） + 本文档记录 | Windows 10/11 |

> 说明：winspool 仅存在于 Windows，本项目通过 `Backend` 抽象把协议层全部放到可测的 file 后端上跑通；对 Windows 侧无法自动化的部分，采取「结构体与常量对照 SDK 头文件核对 + gcc sizeof/offset 比对 + 源码守卫测试」三重防护，Windows 真机只验最后一步。

## 6. 遗留风险与建议

| # | 风险 | 影响 | 建议 |
|---|---|---|---|
| 1 | 本开发环境无 Windows，**真实出纸**未在受控环境验证 | 部署第一步可能遇到驱动/端口细节问题 | 按《01-需求文档》§7 UAT 清单逐项确认，先跑 `diag` 再 `install`，状态页用「打印测试页」分段验证 |
| 2 | 防火墙规则依赖管理员权限运行 | 非管理员运行时客户端连不上 9100 | `install` 必须 UAC 提权；日志有「跳过防火墙配置」警告 |
| 3 | 部分虚拟打印机驱动名含关键字之外的厂商命名 | 可能漏过滤 | 用配置台勾选模式（FR-08）从根上规避，或调 `exclude_keywords` |
| 4 | 状态页公开（无鉴权） | 局域网内可见打印机与作业元信息（来源 IP、文档名、字节数，**不含内容**） | 接受该取舍；如需收紧，可后续为状态页加只读令牌 |
| 5 | 口令以明文打印在首次运行输出/日志中 | 同机可读日志者可获知初始口令 | 登录后立即在配置台改口令；日志文件权限随目录 ACL |
