# NetPrintServer 网络打印服务器

把 Windows 主机上的本地打印机（如 EPSON LQ-630K 针式打印机、USB/并口打印机）转换为**网络打印服务器**，局域网内的 Windows 7 / 10 / 11 客户端可以直接连接打印，无需共享、无需域环境。

```
 客户端 (Win7/10/11)                 打印服务器主机                 本机打印机
┌──────────────────┐  TCP RAW 9100  ┌──────────────────┐  USB/LPT   ┌──────────┐
│ 标准 TCP/IP 端口 │ ─────────────► │ netprintserver   │ ─────────► │ LQ-630K  │
│ + 真实型号驱动   │  (或 LPD 515)  │ Windows 打印队列 │  打印驱动  │ 针式打印机│
└──────────────────┘                └──────────────────┘            └──────────┘
```

## 特性

- **免共享、免域**：走标准 TCP/IP 打印端口协议（RAW 9100），Windows 7 / 10 / 11 客户端原生支持
- **兼容 LPD/LPR**（RFC 1179，端口 515）作为备选接入方式
- **单文件 EXE**，无 .NET / Python 等运行库依赖；同时提供 64 位与 32 位版本，兼容老 Win7 机器
- **Windows 服务**方式运行，开机自启；也支持前台调试运行
- **自动配置防火墙**入站规则（首次以管理员运行时）
- **自动发现**本机打印机，并**默认只转换你勾选的打印机**（虚拟打印机默认跳过；可用 `include_keywords` 精确指定）
- **网页图形化配置（需登录）**：勾选要转换的打印机、改端口/协议/超时、改口令，保存后**立即热生效**（改错端口会自动回滚，不会把管理页搞丢）
- **Web 状态页**：打印机状态、最近作业、被跳过的打印机、一键打印测试页
- `diag` 自检命令：一条命令看清 winspool 调用、枚举结果、端口分配，排障不用猜
- 作业经 Windows 打印后台处理（spooler）转发，打印机忙/脱机时自动排队

## 一、服务器端部署（接打印机的那台电脑）

前提：
1. 打印机已用 USB/并口接到这台电脑，**本机能正常打印**（驱动已装好）；
2. 记下打印机驱动的准确名称（后面客户端要用同一个驱动），查看方法见 FAQ 1。

步骤：

1. 把整个 `NetPrintServer` 文件夹放到一个固定位置（如 `C:\NetPrintServer`，**不要放在桌面/临时目录**）。
2. 双击 **`安装为服务.bat`**（会弹 UAC，点“是”）。
   - 自动写入配置 `config.json`、创建服务 `NetPrintServer`（开机自启）并**立即启动**、放行防火墙端口。
   - 窗口会打印「客户端连接信息」，**记下本机 IP 和端口**（默认 `IP:9100`）。
   - 首次运行还会打印**网页配置页的初始口令**（形如 `已生成网页配置页登录账号：用户名 admin，口令 XxXxXxXxXx`），**请记下来**；忘了可在服务器执行 `netprintserver.exe password 新口令` 重置。
3. 打开**配置页** `http://<服务器IP>:8080/config`，用上面的账号登录，**勾选要把哪几台打印机转换为网络打印**，点「保存并应用」。
4. 打开状态页 `http://<服务器IP>:8080/`，确认：
   - 勾选的打印机在列表里、状态为「就绪」；
   - 点打印机行尾的 **「打印测试页」**，主机上这台打印机应出一页 ASCII 测试页。

常用命令（管理员 CMD）：

```
netprintserver.exe install      安装服务（开机自启）
netprintserver.exe start        启动服务
netprintserver.exe stop         停止服务
netprintserver.exe status       查看服务与端口状态
netprintserver.exe diag         自检（排障用：打印 winspool 调用与打印机枚举原始结果）
netprintserver.exe printers     列出本机打印机
netprintserver.exe password 新口令   设置网页配置页登录口令（不给参数则随机生成并打印）
netprintserver.exe uninstall    卸载服务
netprintserver.exe run          前台运行（调试）
```

## 二、客户端接入

### 方式 A：一键脚本（推荐）

把 `client\` 文件夹拷到客户端电脑，**管理员身份**运行：

- Windows 10 / 11：右键 `install-win10.ps1` →「使用 PowerShell 运行」，或 CMD 中：
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File install-win10.ps1 -Server 192.168.0.10 -Driver "EPSON LQ-630K"
  ```
- Windows 7：双击 `install-win7.bat`（会自动请求 UAC），按提示输入服务器 IP。

脚本做的事：ping 检测 → 创建 TCP/IP 端口（RAW，自动关闭 SNMP）→ 用指定驱动建打印机 → 打印 Windows 测试页。

参数（都可省，省了就交互式询问）：

| 参数 | 说明 | 默认 |
|---|---|---|
| `-Server` | 打印服务器 IP | 必填（可交互输入） |
| `-Port` | RAW 端口 | 9100 |
| `-Driver` | 客户端已安装的驱动名，如 `"EPSON LQ-630K"` | 交互选择 |
| `-PrinterName` | 客户端上显示的打印机名 | `网络打印-<IP>_<端口>` |
| `-NoTest` | 不打印测试页 | — |
| `-Remove` | 卸载本脚本创建的打印机和端口 | — |

### 方式 B：手动添加（不用脚本）

1. 控制面板 → 设备和打印机 → **添加打印机** → 「我需要的打印机不在列表中」；
2. 选 **「使用 TCP/IP 地址或主机名」** → 主机名填服务器 IP（如 `192.168.0.10`）；
3. 端口检测界面若询问设备类型，选 **「自定义」→ 设置**：协议选 **RAW**、端口号 **9100**、**取消勾选 SNMP**；
4. 驱动选择打印机真实型号（如 EPSON LQ-630K，与服务器本地驱动一致）；
5. 打印测试页验证。

> 服务器上有几台打印机，就有几个端口（9100、9101、9102…），对应关系见状态页「打印端口与打印机」表。

### 方式 C：LPR 端口（备选）

1. 客户端：控制面板 → 程序 → 启用或关闭 Windows 功能 → 勾选 **「LPR 端口监视器」**；
2. 添加打印机时选「使用 TCP/IP」，设备类型选 **LPR**，地址填服务器 IP，**队列名**填状态页上的 LPD 队列（默认 `PRN1`）；
3. 驱动同上。

## 三、网页配置管理（http://服务器IP:8080/config）

不再需要手动编辑配置文件。浏览器打开配置页，用管理员账号登录（默认用户名 `admin`，初始口令在首次运行时打印，也可用 `netprintserver.exe password 新口令` 重置）：

| 区块 | 能做什么 |
|---|---|
| **1. 选择要转换的打印机** | 三种模式：①**只转换勾选的打印机**（推荐，其它打印机完全不暴露）②自动：全部真实打印机（跳过 PDF/传真等虚拟打印机）③全部（含虚拟）。打印机列表带驱动、端口、状态和当前分配，一眼看清谁被转换了、谁被跳过及原因 |
| **2. 网络与端口** | 服务器名称、绑定网卡 IP（留空=全部网卡）、RAW 起始端口（客户端连这个）、状态页端口、LPD 开关与端口、防火墙自动放行 |
| **3. 高级设置** | 包含/排除关键字、单个作业大小上限、空闲超时、手动端口绑定（bindings JSON，可把某台打印机钉死在固定端口） |
| **4. 安全** | 显示/修改登录口令（修改后其它设备需重新登录） |

**保存并应用**：点一下即写入 `config.json` **并立即热重启所有监听**，不需要停服务、不需要重启电脑。

- 改错端口/网卡导致新配置起不来？程序会**自动回滚**到原配置并恢复原监听，管理页不会丢；配置页顶部会显示「上次应用」结果，详细原因见 `netprintserver.log`。
- 状态页（`http://IP:8080/`）是**只读**的，任何人都能看打印机状态；只有配置页和配置接口需要登录。

### 安全设计（防止别人随意改动）

- 口令只保存为**加盐 SHA-256 哈希**，不存明文；登录会话放在服务端，Cookie 为 `HttpOnly`，12 小时无操作自动失效；
- 登录**连续失败 5 次锁定 60 秒**，防暴力猜测；
- 所有写操作要求自定义请求头 + 同源 `Origin` 校验（跨站页面无法伪造），未登录访问配置接口直接 401；
- 网页端**不允许关闭状态页**（避免把自己锁在管理入口外）；如需彻底关闭外网访问，可在 `config.json` 里设 `"web_enabled": false`（改回需编辑文件或重装）。

## 四、状态页（http://服务器IP:8080）

- **打印端口与打印机**：每台打印机的 RAW 端口、LPD 队列、实时状态（就绪/缺纸/脱机…）、队列中作业数、一键「打印测试页」；
- **最近作业**：来源 IP、文档名、字节数、状态（接收中/排队/打印中/已完成/失败）；
- 状态页每 8 秒自动刷新；`/api/status` 提供 JSON 格式。

## 五、配置文件 config.json（也可全部用网页配置，无需手改）

首次运行自动生成，与 exe 同目录。**推荐用网页配置页修改**（保存即热生效）；直接手改文件时，改完执行 `netprintserver.exe stop` + `start`（或重启服务）生效。

**只转换指定的打印机**（最常用，网页里勾选即可，等价配置）：

```jsonc
{
  "selection_mode": "selected",                      // selected=只转换下面列出的；auto=自动全部真实打印机；all=全部含虚拟
  "selected_printers": ["EPSON LQ-630K", "SHARP MX-3128UC（财务）"]
}
```

```jsonc
{
  "server_name": "NetPrintServer 网络打印服务器",
  "bind_ip": "",                 // 留空=监听所有网卡；可填内网 IP 只监听该网卡（127.0.0.1/localhost 仍可访问）
  "backend": "auto",             // auto=Windows 上用打印后台处理程序
  "auto_assign": true,           // 自动为本机打印机分配端口
  "start_port": 9100,            // 自动分配起始端口（9100, 9101, …）
  "bindings": [                  // 可选：手动固定绑定（优先于自动分配）
    { "port": 9100, "queue": "PRN1", "printer": "EPSON LQ-630K" }
  ],
  "lpd_enabled": true,           // 是否启用 LPD(515)
  "lpd_port": 515,
  "web_enabled": true,           // 是否启用状态页
  "web_port": 8080,
  "web_token": "…",              // 状态页“打印测试页”的令牌（自动生成，勿外泄）
  "firewall": true,              // 启动时自动更新防火墙入站规则（需管理员）
  "max_job_bytes": 104857600,    // 单个作业大小上限（默认 100MB）
  "idle_timeout_sec": 60,        // 客户端发完数据不关连接的兜底超时（秒）
  "log_file": "netprintserver.log",

  // 打印机筛选（默认跳过 PDF/XPS/传真/虚拟绘图仪等软件打印机）
  "include_keywords": [],        // 非空时，只有名称/驱动命中关键字的打印机才暴露，例如 ["LQ-630K"]
  "exclude_keywords": ["PDF","XPS","Fax","传真","OneNote","Virtual","虚拟","导出","WPS","pdfFactory","Software Printer"],
  "exclude_port_prefixes": ["PORTPROMPT:","FILE:","SHRFAX:","FPP","NUL:","RDP","TSC"],
  "keep_virtual_printers": false // true = 不过滤，虚拟打印机也分配端口
}
```

**网页配置页登录凭据**（由 `netprintserver.exe password 新口令` 或配置页自动维护，一般不用手写）：

```jsonc
{
  "admin_user": "admin",
  "admin_password_hash": "盐$SHA256(盐+口令)"   // 只存哈希，不含明文
}
```

**只暴露针式打印机**（推荐，避免把车间的网络复印机也暴露出去）：

```jsonc
{
  "include_keywords": ["LQ-630K"]
}
```

**多台打印机**：`auto_assign: true` 时自动 `9100、9101、9102…` 依次分配，队列名 `PRN1、PRN2…`，分配结果写入 `config.state.json`，重启不变。插拔打印机后 20 秒内自动检测新机。

**手动绑定示例**：想让某台打印机永远固定在 9100，就在 `bindings` 里写死它；没写的打印机仍然自动分配。

## 六、工作原理

1. 客户端用**真实驱动**把文档渲染成打印机语言（LQ-630K 即 ESC/P 字节流），经 TCP/IP RAW 端口发给服务器 9100 端口；
2. 服务器把字节流用 `StartDocPrinter/WritePrinter` 原样提交给本机 Windows 打印队列（数据类型 RAW，**不做任何转换**）；
3. 本机驱动 + 打印后台把作业从 USB/并口送出，打印机出纸。

因此：**客户端必须安装与打印机匹配的驱动**（和直连本机打印的要求完全一样）；服务器端只是转发字节，字体、页宽、纸张设置全部由客户端驱动决定。打印机忙时由 Windows 队列排队，多客户端并发互不影响。

## 七、常见问题

**1. 客户端驱动哪里来？驱动名怎么查？**
EPSON LQ-630K 驱动：打印机附带光盘，或 Epson 官网/驱动人生等下载；装好后在**服务器**上执行 `netprintserver.exe printers`，或在服务器「设备和打印机」属性里看，客户端选驱动时用**完全相同的名字**。服务器上若能在本机打印，说明驱动没问题。

**1.1 状态页只显示了一部分打印机（WPS PDF、传真、XPS 不见了）？**
这是有意为之：软件虚拟打印机（打印到 PDF/文件/传真）当网络打印服务器没有意义，默认跳过，状态页底部会列出「已自动跳过的打印机」。
- 想只暴露某一台（比如 LQ-630K）：`config.json` 里设 `"include_keywords": ["LQ-630K"]`；
- 想把跳过的也暴露：`"keep_virtual_printers": true`，或在 `bindings` 里手动写死。

**2. 客户端连接超时/打印没反应？**
逐项排查：
- 服务器状态页能否打开？不能 → 网络/防火墙问题；
- 客户端 `ping <服务器IP>`、`telnet <服务器IP> 9100`（或 PowerShell `Test-NetConnection <IP> -Port 9100`）；
- 防火墙：以管理员再跑一次 `安装为服务.bat`，或手动放行：
  ```
  netsh advfirewall firewall add rule name=NetPrintServer dir=in action=allow protocol=TCP localport=9100,9101,515,8080
  ```
- 服务器有多个网卡/装了 VPN：把 `bind_ip` 设成内网 IP，确认客户端连的是同一网段地址。

**3. Win11 客户端连不上 `\\服务器\共享`，本程序还能用吗？**
能。Windows 11 默认禁用 SMB1，无法访问 Win7 主机的共享；Win10 的 2004 之后版本对共享也有签名要求。**RAW 9100 不走共享、不走 SMB**，不受影响 —— 这正是本程序的意义。

**4. 状态页里打印机显示「离线/未连接」？**
USB 线松了、打印机没开机、或驱动被卸载。恢复后 20 秒内自动变回就绪，端口不变。

**5. 打印出来乱码/格式不对？**
服务器只做字节转发，乱码通常是：客户端驱动选错（选成了通用/文本驱动）、或客户端与实际打印机型号不符。核对驱动名；若中文票据用点阵字体，需在客户端驱动里选择打印机自带中文字体。

**6. 想 100% 确认链路通不通？**
- 服务器状态页点「打印测试页」→ 验证 **服务器→打印机** 段；
- 客户端打印 Windows 测试页/文档 → 验证 **客户端→服务器→打印机** 全链路；
- 出问题时先在服务器上跑 `netprintserver.exe diag`（自检），把输出发我：它会打印 winspool 调用是否可用、枚举到几台打印机、每台的状态/端口/驱动；
- 排障时可把 `config.json` 里 `"backend": "file"`：作业不再送打印机，而是存成 `spool\打印机名\*.prn` 文件，用记事本/十六进制看数据是否到达（用完记得改回 `"auto"`）。

**7. 32 位系统 / 很老的 Win7？**
用 `netprintserver-x86.exe`（把主 exe 改名或直接运行它，安装服务时它是独立程序，建议 32 位系统上直接用 x86 版本操作全部命令）。

**8. 日志在哪？**
`config.json` 同目录 `netprintserver.log`，含每次作业的来源 IP、字节数、结果。

**9. 如何换端口 / 只监听一块网卡？**
直接用网页配置页改（推荐），或改配置文件后重启服务。设了 `bind_ip` 只监听指定网卡时，**本机仍可用 `http://127.0.0.1:8080` / `localhost` 访问**（程序会自动额外监听回环地址），其它网卡则不暴露。

**10. 忘了网页配置页的口令？**
在服务器上执行 `netprintserver.exe password 新口令`（不给参数则随机生成并打印），然后重启服务：`net stop NetPrintServer` + `net start NetPrintServer`。

**11. 在配置页保存后，打印机没按预期生效？**
配置页顶部会显示「上次应用」的结果：
- 显示「配置已应用」= 已生效；
- 显示「上次应用失败…（已回滚到原配置）」= 新配置起不来（端口被占用等），已自动回滚，详细原因看 `netprintserver.log`；
- 若刚改过端口/网卡：用新地址访问，旧地址会自动失效。

**12. 只想转换针式打印机，其它一概不要？**
配置页选「**只转换勾选的打印机**」，只勾 LQ-630K 那一台，保存即可——其余打印机（含网络复印机、PDF/传真类）完全不会开放端口。
